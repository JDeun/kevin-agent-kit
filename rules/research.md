# Research

- Read the wiki map and the relevant synthesis pages before researching or
  designing. This avoids repeating work and shows what is already believed.
- Land findings in a synthesis page with cited sources before calling the work
  done. Research that exists only in a scratch file or a chat is lost.
- Add raw material as a dated source and never edit it. Immutable sources keep
  every claim auditable.
- Mark contradictions instead of resolving them silently. A person decides
  which source wins.
